# Wkład i czego się nauczono

Projekt indywidualny: Piotr Czarnocki. Przy kodzie pomaga Claude Code, a autor odpowiada za kod i musi umieć go wyjaśnić.

## Etap „Fundament”

### Co powstało

- Aplikacja Blazor Web App (.NET 10, Interactive Server) z MudBlazor.
- PostgreSQL 18 w Docker Compose, z osobnymi rolami dla migracji i działającej aplikacji.
- Tabele `Users` i `AuditLog` oraz pierwsza migracja.
- Logowanie Google z listą dozwolonych adresów i dziennikiem logowań.
- Testy jednostkowe i integracyjne, CI, CodeQL, Dependabot.

### Podział pracy

- **Autor:** specyfikacja, decyzje o zakresie i technologiach, akceptacja planu.
- **Claude Code:** implementacja według specyfikacji i zaakceptowanego planu.
